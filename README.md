# Visualizador do Acervo ÉPURA

Página do grupo ÉPURA (UFMT) para organizar a produção do grupo e revisar o que do acervo pode ir para o site.

Este repositório tem só o código da página. Ele não contém dados: a página busca os dados num Apps Script da conta do grupo, e só responde para quem abre com um link pessoal válido.

O código-fonte fica em `catalogo-epura/revisao-web/Pagina.html`; `index.html` é uma cópia dele.
